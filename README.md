# CLARA Showcase Website

Public, single-page research showcase for **CLARA** (Clinical Learning, Assessment & Review Assistant). This is a polished content site—not a working application.

## Local preview

```bash
npm install
npm run dev
```

Then open the URL Vite prints (default `http://localhost:5173`).

```bash
npm run build    # production build to dist/
npm run preview  # preview the production build
```

## Content sources

Primary copy comes from the ShahLab.AI Phase 2 proposal. Supporting messaging and figures come from the pitch deck and research poster in `reference/`.

## Notes

- No login, uploads, backend, or app features.
- Existing annotation tool screenshots are labeled separately from planned Phase 2 learner UI.
- Labeled placeholders mark missing proposal figures (Fig. 1 / Fig. 2) when a distinct export was not available.
